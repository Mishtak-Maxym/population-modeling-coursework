# Реалізовані задачі проєкту

Цей файл описує задачі, які були виконані в межах курсової роботи та відображені в GitHub Issues.

## 1. Підготовка структури репозиторію

- створено README;
- додано `requirements.txt`;
- додано `.gitignore`;
- визначено структуру `src/`, `docs/`, `database/`.

## 2. Реалізація математичних моделей

- модель Мальтуса;
- логістична модель Ферхюльста;
- дискретна модель Рікера;
- дискретна модель Бевертона–Голта;
- матрична модель Леслі;
- стохастична логістична модель;
- модель з ефектом Аллі.

- порівняння експоненційної та логістичної моделей;
- вплив параметра `K`;

- порівняння моделей Рікера та Бевертона–Голта;
- зміна режимів у моделі Рікера;
- аналіз вікової структури за моделлю Леслі;
- стохастичні траєкторії;
- пороговий ефект Аллі.
