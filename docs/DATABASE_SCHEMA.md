# Структура бази даних

База даних потрібна для збереження інформації про математичні моделі, сценарії експериментів, результати моделювання, вікові групи для моделі Леслі та User Stories.

## Основні таблиці

### `model_types`

Зберігає перелік математичних моделей, які реалізовані в курсовій роботі.

Поля:

- `id` — первинний ключ;
- `code` — короткий код моделі, наприклад `malthus`, `verhulst`, `ricker`;
- `name` — повна назва моделі;
- `description` — короткий опис.

### `experiment_scenarios`

Зберігає параметри конкретного комп’ютерного експерименту.

Поля:

- `id` — первинний ключ;
- `model_type_id` — посилання на модель;
- `title` — назва сценарію;
- `n0` — початкова чисельність;
- `r` — коефіцієнт росту;
- `k` — місткість середовища;
- `a` — поріг Аллі;
- `sigma` — інтенсивність випадкового шуму;
- `steps` — кількість дискретних кроків;
- `time_start`, `time_end` — межі часу для безперервних моделей;
- `notes` — пояснення сценарію.

### `simulation_runs`

Зберігає окремі запуски моделювання.

Поля:

- `id` — первинний ключ;
- `scenario_id` — посилання на сценарій;
- `seed` — значення генератора випадкових чисел для стохастичних моделей;
- `status` — стан запуску;
- `figure_filename` — назва файлу з графіком;
- `created_at` — дата створення запису.

### `simulation_points`

Зберігає точки траєкторії моделювання.

Поля:

- `id` — первинний ключ;
- `run_id` — посилання на запуск;
- `step_index` — номер кроку;
- `time_value` — значення часу;
- `population_value` — чисельність популяції.

### `age_groups`

Зберігає вікові групи для моделі Леслі.

Приклад груп:

- молодь;
- репродуктивна група;
- старші особини.

### `leslie_matrix_values`

Зберігає елементи матриці Леслі для конкретного сценарію.

Поля:

- `scenario_id` — сценарій моделі Леслі;
- `row_index` — номер рядка матриці;
- `column_index` — номер стовпця матриці;
- `value` — значення елемента матриці.

### `user_stories`

Зберігає документацію у вигляді User Stories.

Поля:

- `role` — роль користувача;
- `goal` — дія або потреба;
- `benefit` — користь;
- `acceptance_criteria` — критерії приймання.

## Зв’язки між таблицями

- `model_types` 1 → N `experiment_scenarios`;
- `experiment_scenarios` 1 → N `simulation_runs`;
- `simulation_runs` 1 → N `simulation_points`;
- `experiment_scenarios` 1 → N `leslie_matrix_values`.
