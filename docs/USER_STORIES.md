# User Stories

## US-01. Перегляд доступних моделей

**Як** студент,  
**я хочу** бачити перелік реалізованих математичних моделей,  
**щоб** розуміти, які підходи використані в курсовій роботі.

### Критерії приймання

- У README наведено перелік моделей.
- У коді є окремі функції для кожної моделі.
- Назви моделей збігаються з теоретичною частиною курсової.

## US-02. Моделювання експоненційного росту

**Як** дослідник,  
**я хочу** запустити модель Мальтуса з параметрами `N0`, `r` і `t`,  
**щоб** отримати базову траєкторію необмеженого росту.

### Критерії приймання

- Функція `malthus` повертає масив значень `N(t)`.
- При `r > 0` чисельність зростає.
- Модель використовується для порівняння з логістичною моделлю.

## US-03. Моделювання логістичного росту

**Як** дослідник,  
**я хочу** запустити модель Ферхюльста з параметрами `N0`, `r`, `K`,  
**щоб** дослідити насичення популяції в обмеженому середовищі.

### Критерії приймання

- Функція `logistic_continuous` реалізує аналітичний розв’язок.
- При додатних параметрах траєкторія наближається до `K`.
- Модель використовується в експериментах зі зміною `K` та `r`.

## US-04. Порівняння дискретних моделей

**Як** студент,  
**я хочу** порівняти моделі Рікера та Бевертона–Голта,  
**щоб** показати різницю між коливальною та стабільнішою дискретною динамікою.

### Критерії приймання

- Реалізовано функції `ricker` і `beverton_holt`.
- Обидві функції повертають послідовність значень за кроками.
- Побудовано графік порівняння моделей.

## US-05. Аналіз вікової структури

**Як** дослідник,  
**я хочу** використати матричну модель Леслі,  
**щоб** оцінити вплив вікових груп на довгострокову динаміку популяції.

### Критерії приймання

- Реалізовано функцію `leslie_matrix_example`.
- Результатом є історія зміни трьох вікових груп.
- Побудовано графік для молоді, репродуктивної групи, старших особин і сумарної чисельності.

## US-06. Дослідження випадкових факторів

**Як** дослідник,  
**я хочу** запускати стохастичну логістичну модель з різними `seed`,  
**щоб** побачити, як випадкові збурення змінюють траєкторію.

### Критерії приймання

- Реалізовано функцію `stochastic_logistic`.
- Значення чисельності не стають від’ємними.
- Побудовано кілька стохастичних траєкторій.

## US-07. Дослідження ефекту Аллі

**Як** дослідник,  
**я хочу** змінювати початкову чисельність відносно порогу `A`,  
**щоб** показати умови виживання або вимирання популяції.

### Критерії приймання

- Реалізовано функцію `allee_discrete`.
- Для `N0 < A` траєкторія показує спад.
- Для `N0 > A` траєкторія може перейти до зростання та стабілізації.

## US-08. Збереження структури даних

**Як** розробник,  
**я хочу** мати SQL-схему бази даних,  
**щоб** зберігати моделі, сценарії, запуски та точки моделювання.

### Критерії приймання

- Є файл `database/schema.sql`.
- Є документація `docs/DATABASE_SCHEMA.md`.
- Таблиці описують моделі, експерименти, результати та User Stories.
