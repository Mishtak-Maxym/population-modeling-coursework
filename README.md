# Комп’ютерне моделювання динаміки чисельності ізольованих популяцій

Репозиторій створено на основі курсової роботи з теми **«Комп’ютерне моделювання динаміки чисельності ізольованих популяцій»**.

## Мета проєкту

Побудувати, програмно реалізувати та порівняти математичні моделі, які описують зміну чисельності ізольованих популяцій.

## Реалізовані моделі

- експоненційна модель Мальтуса;
- логістична модель Ферхюльста;
- дискретна модель Рікера;
- дискретна модель Бевертона–Голта;
- віково-структурована матрична модель Леслі;
- стохастична логістична модель;
- модель з пороговим ефектом Аллі.

## Структура репозиторію

```text
src/
  pop_model_code.py       # реалізація математичних моделей
  pop_figures_code.py     # побудова графіків для експериментів

database/
  schema.sql              # структура бази даних проєкту

docs/
  DATABASE_SCHEMA.md      # опис структури БД
  USER_STORIES.md         # документація у вигляді User Stories
  PROJECT_TASKS.md        # перелік реалізованих задач
```

## Запуск

```bash
pip install -r requirements.txt
python src/pop_figures_code.py
```

Після запуску будуть згенеровані рисунки `fig31.png` – `fig38.png`, які відповідають експериментам з курсової роботи.

## Технології

- Python
- NumPy

- SQLite / SQL-схема для опису даних експериментів
